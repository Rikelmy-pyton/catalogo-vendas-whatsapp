# 🛍️ Vitrine Digital Inteligente - Checkout via WhatsApp

Este projeto é uma solução de e-commerce leve e funcional, desenvolvida para digitalizar pequenos comércios e consultores de vendas na região de Porto Seguro, Arraial d'Ajuda e Trancoso.

## 🚀 Demonstração Online
O projeto pode ser acessado em tempo real através do link:
👉 https://rikelmy-pyton.github.io/catalogo-vendas-whatsapp/

## ⚠️ AVISO DE NAVEGAÇÃO
**Para visualizar todas as fotos dos produtos, basta deslizar/passar para o lado sobre a imagem do item.** Desenvolvemos esse sistema de carrossel para facilitar a visualização de detalhes sem ocupar muito espaço na sua tela.

## ✨ Diferenciais Técnicos
- **Sistema de Slides:** Navegação moderna e intuitiva entre as fotos dos produtos.
- **Foco em Conversão:** Integração direta com a API do WhatsApp para fechamento de pedidos.
- **Arquitetura de Dados:** Gerenciamento centralizado de estoque via JavaScript (`estoque.js`).
- **Performance:** Carregamento otimizado para dispositivos móveis (4G/5G).
