# 🛍️ Vitrine Digital Inteligente - Checkout via WhatsApp

Este projeto é uma solução de e-commerce leve e funcional, desenvolvida para digitalizar pequenos comércios e consultores de vendas na região de Porto Seguro, Arraial d'Ajuda e Trancoso.

## 🚀 Demonstração Online
Clique no link abaixo para visualizar a loja em funcionamento:
[https://rikelmy-pyton.github.io/catalogo-vendas-whatsapp/]

## ✨ Diferenciais do Projeto
- **Foco em Conversão:** Botão de compra que gera um pedido formatado diretamente para o WhatsApp do vendedor.
- **Alta Performance:** Site extremamente leve, ideal para conexões móveis (4G/5G) de turistas e moradores.
- **Gestão Simplificada:** Controle de estoque e preços centralizado em um arquivo JavaScript separado, facilitando a manutenção.
- **Design Responsivo:** Interface otimizada para smartphones e tablets.

## 🛠️ Tecnologias Utilizadas
- **HTML5 & CSS3:** Estrutura e estilização moderna.
- **JavaScript:** Lógica de carrinho de compras e integração com API do WhatsApp.
- **GitHub Pages:** Hospedagem gratuita e segura com 100% de disponibilidade.

## 📝 Como usar este modelo
Para adaptar esta loja para outro negócio, basta atualizar o arquivo `estoque.js` com os novos produtos, fotos e preços.
